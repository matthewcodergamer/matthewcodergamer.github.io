About Minecraft Web

Minecraft Web is an independent fan project: a browser game, plus a set of original notes for people who run their own Java servers. It is not an official Minecraft site, and it is not a hosting company.

Who writes this

The site is published by Matthew Coder. The game at Minecraft Web is the browser project. The pages under Server guides are written for server owners and community admins, aimed at readers 16 and older, who are comparing hardware and startup flags. Those guides are maintained by the same publisher as the game. They are not sponsored posts.

What we will and will not claim

Install commands are written for Ubuntu and checked against the current Paper and Java 21 setup described on each page. Performance ranges, such as how much less CPU Paper tends to use than Vanilla, are planning figures. They are not a promise that your world will hit a specific tick rate. When a number would require a lab we did not run, the page says so.

Hosting prices are typical public ranges, dated on the article. They are not quotes, and this site does not take affiliate commissions for hosting recommendations. If that ever changes, the article will say so at the top, and a commission will not decide the ranking.

Corrections

Paper changes flags and config paths. If a command on this site disagrees with Paper’s own documentation, Paper is right, and we want the correction. Use the contact page.

The editorial policy describes how pages are updated. The privacy policy describes ads, cookies, and the data the game keeps on your device.
