Contact

Use this page for corrections, privacy questions, and anything about a purchase made through the game. There is no support desk that will restart a server for you — the guides are documentation, not managed hosting.

Write to the project

Open an issue on the game repository: github.com/matthewcodergamer/MinecraftWeb/issues. That is the inbox we actually read. Include the page URL if you are reporting a mistake in a guide, and the command that failed if you are reporting an install step.

What to send, and what not to send

  • For a wrong flag, a dead link, or a config path that Paper has moved: the page URL and what the official docs say now.
  • For privacy: say which section of the privacy policy your question is about. Do not send card numbers. Purchases are handled by Stripe, and we never see the card.
  • For the browser game: what device, which browser, and what you expected to happen.

We do not offer paid server setup through this inbox. If you want someone to administer a machine, hire an administrator. The install guide is the free version of that job, written down.
