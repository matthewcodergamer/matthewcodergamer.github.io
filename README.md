# matthewcodergamer.github.io

Root of the GitHub Pages domain. It holds:

- `index.html`: landing page linking to the game at [/MinecraftWeb/](https://matthewcodergamer.github.io/MinecraftWeb/), with the Google AdSense site-verification code.
- `ads.txt`: the AdSense authorized-seller line. Google only reads it at the domain root.
- `privacy.html`: privacy policy (AdSense cookies, Stripe purchases, local saves).
