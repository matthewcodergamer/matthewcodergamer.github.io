# matthewcodergamer.github.io

Public landing page for **Minecraft Java Edition v26.3** in the browser.

The game shell, WebAssembly client, and resource archive are served from the
canonical Hugging Face Space. GitHub Pages intentionally hosts only the small
redirect entry point because the production Wasm module is larger than the
Git repository file limit.

Canonical build: https://matthewcodergamer-minecraft-browser.static.hf.space/
